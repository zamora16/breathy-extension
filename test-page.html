📋 Instrucciones

Esta página te ayuda a probar todas las funcionalidades de Breathy de manera controlada:

  1. Abre el popup de Breathy (icono en la barra de herramientas)
  2. Registra esta página como "sitio personalizado"
  3. Recarga la página para activar Breathy
  4. Nota el pequeño ícono de tutorial personalizado en la esquina superior derecha del popup
  5. Usa los botones de abajo para probar funcionalidades
